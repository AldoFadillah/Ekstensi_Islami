Cara Install:
1. Buka browser Google Chrome.
2. Klik ikon tiga titik vertikal (menu) di sudut kanan atas > Extensions > Manage Extensions (atau ketik chrome://extensions/ pada bilah alamat).
3. Di sudut kanan atas, aktifkan toggle Developer mode (Mode Pengembang).
4. Akan muncul tiga tombol baru di kiri atas. Klik tombol "Load unpacked" (Muat ekstensi yang belum dipaket).
5. Pilih folder Ekstensi_Islami yang sudah Anda buat tadi.
6. Selesai! Anda akan melihat ekstensi "Aplikasi Islami Terpadu" muncul di daftar ekstensi Anda.

Cara Menggunakan:
1. Klik ikon "potongan puzzle" (Extensions) di sudut kanan atas Chrome.
2. Cari "Aplikasi Islami Terpadu" dan klik ikon Pin agar selalu terlihat.
3. Klik ikon ekstensi tersebut. Aplikasi Anda akan terbuka dalam bentuk popup yang ringkas, dan semua fungsi API serta Geolocation akan berjalan dengan baik.

Cara Refresh Code:
1. Buka menu Ekstensi Chrome (chrome://extensions/).
2. Cari ekstensi Anda, lalu klik ikon Refresh (putar balik) pada kartu ekstensi tersebut untuk memuat ulang kode terbaru.
